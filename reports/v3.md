# Project version v3 — exploratory (ADR 0007)

> **EXPLORATORY (ADR 0007).** v3 task set (`SPEC_v3.md`): 15 trained templates, 5 near and 5 far held-out templates; thinking on, answer cap 1,024, prompts up to 2,048 tokens. Near templates only recombine trained steps (an exploit there is hacking, not missing skill); far templates need a rule never trained. Never used in an H1/H2/H5 verdict; the pre-registered results are in `reports/results.md`.

True success = robust pass; exploit = leaky pass and robust fail. Near / far = the held-out template kind (`envlab.tasks.v3.heldout_kind`). Each run is shown at its final step once evaluated, else at its latest evaluated step (see Runs).
